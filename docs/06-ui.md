# 06 UI

Screen designs for the web game. The visual direction (colors, fonts, mood) is decided in 00 Overview and applies to every screen here. This file covers what each screen shows and how it is laid out. Concept only, no code. All layouts are drafts.

Screens, in the order they are designed: 1) main screen (explore); 2) combat; 3) character status; 4) bag and equipment; 5) skills and fusion; 6) quests and journal; 7) dialogue scenes; 8) online boards. All eight are designed. Screens 1 to 3 were decided with Phat step by step. Screens 4 to 8 were designed by Claude on Phat's instruction (Nov 3, 2026: "whatever is left before Arc 2, use your judgement and tell me what you did"), so their decisions are marked as Claude's choices. Phat reviewed and accepted them on Nov 9, 2026.

## 1. Main screen (explore)

The screen the player spends the most time on when not fighting: the current location of the current floor, where the climber talks to people, takes quests, picks where to go next, and opens every menu.

### Layout (desktop)

```
┌──────────────────────────────────────────────────────────────┐
│ Floor 4 · Murim world     Rec. Lv 7 / Grade E     Coins 1,240 │
│ [floor rule chip]                                  Settings   │
├──────────────────────────────────────┬───────────────────────┤
│                                      │ Character             │
│                                      │ Lv 7  EXP bar         │
│     Background art of the            │ HP bar                │
│     current location                 │                       │
│     (one image, fills the area)      ├───────────────────────┤
│                                      │ Tracked quests        │
│   faint notes and signs from         │ > Main: ...           │
│   other players in a corner          │ > Side: ...           │
├──────────────────────────────────────┴───────────────────────┤
│ Go to:   [Place] [Place] [Place with monsters, sword mark]    │
│ Talk to: [Person] [Person]                                    │
├──────────────────────────────────────────────────────────────┤
│ Status │ Bag │ Skills │ Fusion │ Quests │ Journal │ Board     │
└──────────────────────────────────────────────────────────────┘
```

### Parts

| Part | Design |
| --- | --- |
| Top bar | Floor number and world name, the floor's recommended level and Hero grade (so the player sees at once whether they are strong enough), Tithes, and settings. From floor 9 the Watcher Attention gauge sits beside the Tithes |
| Floor rule chip | A small label under the floor name that always shows the floor's special rule (for example "Reputation is HP" on floor 6). It opens a short explanation when pressed |
| Scene area | One background image of the current location, filling the main area. The image carries the feeling of each world, so it is the center of the screen. Notes and preset signs left by other players appear faintly in a corner and do not cover the story |
| Character panel | Right side, small: level with an EXP bar, and an HP bar. Nothing else, so the screen stays calm |
| Tracked quests | Right side, small: the tracked main quest and up to a few side quests, one line each. Pressing one opens the Quests window |
| Go to | Buttons for the places the climber can move to from here. A place with field monsters has a small sword mark. Travel between cleared floors is in the menu, not a button on every floor |
| Talk to | Buttons for the named people at this location. A person with a bond shows the bond level as small pips on the button |
| Menu bar | Seven buttons: Status, Bag, Skills, Fusion, Quests, Journal (fusion recipes and clues) and Board (online features). Each opens a window over the scene instead of changing the page, so the player never loses the sense of where they are |

### Layout (mobile)

The scene image is on top, filling the width. Below it are the Go to and Talk to buttons in two rows. The seven menu buttons are a tab bar fixed to the bottom. The character panel and tracked quests collapse into one thin bar under the top bar, which expands when pressed. Menu windows open as full-height sheets that slide up from the bottom.

### Decisions

- Choosing where to go and whom to talk to uses button lists, not pressing on the image (decided Nov 3, 2026). This needs only one background image per location, is easy to use on mobile, and can be changed to pressing on the image later without redesigning the screen.
- Windows open over the scene, not as separate pages.
- Floor rules are visible at all times through the rule chip.
- Leaving a note (Claude's choice): at a spot where a note can be left, a small "Leave note" button appears in the scene corner, and it only appears at key spots. See screen 8.

### Decisions on open questions (Nov 9, 2026)

- A resting place uses this same screen, with a Rest button under the Talk to row.
- Travel between floors is a window listing cleared floors, each row with floor number, world name and best clear grade. A floor is replayed from this list to raise its clear grade.
- Special-rule floors get no new screens, only additions to the existing parts: floor 5 has a day/night mark in the top bar; floor 6 relabels the HP bar as Reputation and has an area chip (Public, Semi-private, Private); floor 8's Go to row shows signs in words, not place names, with no map; floor 9 has its Arena bout number in the top bar and a handicap window before each bout.
- The memories lost counter is never shown as a number on any of the climber's screens. It is felt only through NPC lines.

## 2. Combat screen

The turn-based fight screen. The game has no limit on usable skills and has skill tags (Stance, Charge, Form, Aura), so this screen must stay readable with dozens of skills and must always show which tags are active.

### Layout (desktop)

```
┌──────────────────────────────────────────────────────────────┐
│ Floor 4 · [floor rule chip]          Round 3      Turn order  │
│                                      [You][Enemy A][Enemy B]  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│      Enemy A           Enemy B (Elite)        Enemy C         │
│     [enemy art]        [enemy art]            [enemy art]     │
│     HP bar             HP bar                 HP bar          │
│     status icons       status icons           status icons    │
│                                                              │
│                (background art of the floor)                  │
├──────────────────────────────────────┬───────────────────────┤
│ You  Lv 7   HP bar  748/1,020        │ Combat log            │
│ Stance: Brace    Charge: -           │ last 3 to 5 lines     │
│ Form: -    Aura: Bark Skin (-2 HP)   │                       │
│ Statuses: -                          │                       │
├──────────────────────────────────────┴───────────────────────┤
│ [Weapon attack] [Skills >] [Items >] [Switch Stance/Aura]     │
│ [pinned skill 1] [2] [3] [4] [5] [6]                          │
└──────────────────────────────────────────────────────────────┘
```

### Parts

| Part | Design |
| --- | --- |
| Top bar | Floor and the floor rule chip (same as the main screen), the round number, and the turn order strip. Speed (Agility) sets the order, so the player sees ahead who acts next |
| Enemy area | Enemies in a row with art, HP bar and status icons. Elites, mini-bosses and floor masters have a thin gold frame so the dangerous ones are clear at a glance. Pressing an enemy selects it as the target |
| Player status | Bottom left: level, HP bar with numbers, and a fixed line of four tag slots (Stance, Charge, Form, Aura). A Form shows its turns left, an Aura shows its upkeep per turn, and a Charge shows what is held. The slots are always visible, even when empty, because the tag rules are something the player must keep in mind |
| Statuses | Good and bad statuses of the player as small icons with turns left, under the tag slots |
| Combat log | Bottom right: the last 3 to 5 lines, short and neutral. A button opens the full log |
| Main buttons | Four: Weapon attack, Skills, Items, and Switch Stance/Aura. Switching is a separate button because changing a Stance costs the turn, while an Aura switch costs no turn but starts next turn, so the player should not do it by accident |
| Pinned skills | A row of 6 slots under the main buttons, filled by the player with the skills they use most. One press uses the skill at once. This is only a shortcut; every compatible skill can still be used from the full list |
| Skills window | Opens over the fight. Usable skills are shown normally. Skills that cannot be used now are dimmed with a short reason (for example "needs a shield" or "Stance active"). A skill whose tag matches one already active shows what it will replace before it is pressed |

### Layout (mobile)

The fight scene is on top and the enemies are smaller. The player's status is a thin bar below it, with the four tag slots as small icons. The four main buttons and the 6 pinned slots sit fixed at the bottom within thumb reach. The Skills and Items windows slide up as full-height sheets. The combat log collapses to one line, which expands when pressed.

### Decisions

- Pinned skills (decided Nov 3, 2026): the player gets 6 pinned skill slots on the fight screen for fast use, and the full list of skills stays behind the Skills button. This fits the rule that there is no limit on usable skills, and it makes repeated farming fights quicker. The pinned slots are a convenience and do not count in the Hero power score.
- The four tag slots are always visible in the player status.
- Skills that cannot be used are dimmed with a reason, not hidden.
- Switching a Stance or Aura is a separate button from the Skills window.

### Decisions on open questions (Nov 9, 2026)

- The player can flee from field fights only (normal, tough, elite). Fleeing costs the turn, has a chance based on Agility and gives no rewards. There is no fleeing from mini-bosses, floor masters or trials.
- There is one shared row of 6 pinned skills, with no saved sets.
- Fight additions: floor 3's status reset gets a log line and a short screen flash; floor 5's immortal enemies carry an "Immortal until dawn" status icon; floor 6 shows the same relabelled bar and area chip as the main screen; from floor 9 the Attention gauge is also in the top bar, and floor 9 shows its Arena bout number there.

## 3. Character status

A window opened from the menu bar over the current scene. It holds the most information of any screen (core stats, ratings, Hero power grade, class, titles, bonds and clear results), so it is split into four tabs instead of one long page.

### Layout (desktop, Overview tab)

```
┌──────────────────────────────────────────────────────────────┐
│ Status                                              [Close]   │
│ [Overview] [Titles] [Bonds] [Floor clears]                    │
├───────────────────────┬──────────────────────────────────────┤
│ [character art]       │ Name · Class > Branch (+ add-on class)│
│                       │ Lv    EXP bar                        │
│ Weapon  Head          │ (at the level cap: banked EXP bar)    │
│ Body    Gloves        ├──────────────────────────────────────┤
│ Boots   Accessory     │ Core stats: Vitality, Power,          │
│ (press a slot to      │ Agility, Mind                         │
│  open the bag at it)  │ Ratings: Evasion, Guard, Ward         │
│                       ├──────────────────────────────────────┤
│                       │ Hero power grade and score            │
│                       │ Stats bar | Skills bar | Gear bar     │
│                       │ (a mark at half = each part's cap)    │
└───────────────────────┴──────────────────────────────────────┘
```

### Parts

| Part | Design |
| --- | --- |
| Left side | Character art with the six equipment slots (weapon, head, body, gloves, boots, accessory). Pressing a slot opens the bag at that slot |
| Identity | Name, class and the chosen branch after the first advancement, and the add-on hidden class if the climber has found one |
| Level and EXP | Level with an EXP bar. At the level cap the bar changes to the banked EXP (kept up to one level's worth), so the player understands EXP is not lost while waiting for advancement |
| Stats | The four core stats and the three ratings. Pressing one shows where it comes from (class, gear, skills) |
| Hero power grade | The grade, the score, and three bars for the stat, skill and gear parts, each with a mark at half of the score needed for the grade (decided, see Decisions) |
| Titles tab | One equipped title slot and the list of all collected titles with their small permanent bonuses. Titles not yet found show as shadows with a short hint |
| Bonds tab | A list of NPCs the climber has met, each with its bond level as 5 pips, and the gifts they like once discovered |
| Floor clears tab | One row per floor with the best clear grade. Pressing a row shows the four factors (Path, Content, Secrets, Style). Path, Content and Style list which conditions are still missing, so the player knows what to redo to raise the grade. Secrets shows only its score (for example 12/25), never what is missing or how many remain. The hidden SSS condition is not shown at all |

### Layout (mobile)

The tabs become a scrolling strip at the top. The character art and equipment slots move below the main information, and each section collapses into a heading that expands when pressed.

### Decisions

- Hero power grade display (decided Nov 3, 2026): three bars (stats, skills, gear), each with a mark at half of the score needed for the grade. The player can see which part has reached its cap and which part is short. This teaches the cap rule inside the game and prevents the feeling that levelling alone should have raised the grade.
- Four tabs: Overview, Titles, Bonds, Floor clears.
- The banked EXP at the level cap is shown in the EXP bar.
- The memories lost counter is not part of this screen (see open questions).
- Missing secrets stay hidden on the Floor clears tab (decided Nov 9, 2026): the Secrets factor shows only its score.

### Decisions on open questions (Nov 9, 2026)

- Pressing a stat shows only its sources.
- The Hero power breakdown shows the current floor's recommended grade beside the climber's grade.

## 4. Bag and equipment (Claude's design)

One window with four tabs: Equipment, Items, Materials and Workshop. The Workshop is where enhancement and crafting happen, so the player does not need a separate crafting screen.

### Layout (desktop, Equipment tab)

```
┌──────────────────────────────────────────────────────────────┐
│ Bag                                                 [Close]   │
│ [Equipment] [Items] [Materials] [Workshop]                    │
├───────────────────────┬──────────────────────────────────────┤
│ Worn                  │ Selected piece                        │
│ Weapon  [ +4 ]        │ Name · grade · +4                     │
│ Head    [ +2 ]        │ Stat lines, weapon type if a weapon   │
│ Body    [ +4 ]        │ Gear points toward Hero grade: 6      │
│ Gloves  [ +0 ]        │ Compare with the worn piece:          │
│ Boots   [ +3 ]        │ + / - on each line                    │
│ Acc.    [ +0 ]        │ [Equip] [Go to Workshop]              │
│                       ├──────────────────────────────────────┤
│ Set bonuses           │ Carried pieces of this slot (list)    │
│ Healer's 4/6          │                                      │
│ Sect's 2/6            │                                      │
└───────────────────────┴──────────────────────────────────────┘
```

### Parts

| Part | Design |
| --- | --- |
| Equipment tab | The six worn slots on the left with their enhancement level, the selected piece with its lines on the right, and a list of the carried pieces for the same slot. Choosing a carried piece shows plus and minus against the worn one, and its gear points toward the Hero grade. A weapon also shows its weapon type and the proficiency stage needed |
| Set bonuses | Under the worn slots: each set the climber is wearing, how many pieces out of 6, and which bonuses (2, 4, 6 pieces) are active. Pieces of different sets are counted per set, so 2 + 2 + 2 shows three active 2-piece bonuses |
| Items tab | Consumables (healing, cures), enhancement stones, protection charms, class skill books, stage catalysts, bond gifts and key items, as separate sections. Pressing an item shows its use. Skill books show which class they belong to and read with one press, with a short confirm because a book is used up |
| Materials tab | Floor materials grouped by floor with the amount held (Straw Thread, Road Ash and so on), and rare parts. The floor of each material is shown so the player can see which floor to farm |
| Workshop tab | The place where enhancement and crafting happen (see below) |

### Workshop

The Workshop has two modes, Enhance and Craft. It can be opened at any location without combat, because the climber can travel freely and a forced trip to a town would only add walking.

| Mode | Design |
| --- | --- |
| Enhance | Choose a piece. The screen shows its current level, the target level, the chance of success from the rate table, and what a failure does (the piece drops 2 levels; attempts for +1 to +3 never drop). It lists the stone needed (grade equals the target level) and shows how many the climber holds. A protection charm toggle appears only for attempts at +4 and above. A press on Enhance shows a short confirm that repeats the chance and the failure result. The outcome is shown with a short animation and the log line |
| Stones | A section lists the six stone grades of the arc. Each shows its recipe (for example "9 of floor 1, 6 of floor 1, 3 of floor 1" for +1, or the three floors' materials and rare parts for +5) beside what the climber holds, and a Craft button when everything is available. Stone recipes are shown because they are plain costs, not hidden recipes |
| Craft | Experimental crafting: put materials and items into the ingredient slots, with an optional catalyst, and press Try. Recipes are hidden, so nothing is previewed. Known recipes recorded in the Journal can be picked from a list and show their cost. A failed try gives a scrap result, and the result is shown as an item |

### Layout (mobile)

The four tabs become a strip at the top. The Equipment tab shows the six slots as a row of icons, and the selected piece with its comparison below. The Workshop opens as a full-height sheet.

### Decisions (Claude's choices)

- Enhancement and crafting live in the bag as a Workshop tab, not a separate screen.
- The Workshop works at any location without combat.
- The chance of success and the failure result are always shown before an enhancement, and a confirm repeats them.
- Stone recipes are shown plainly; experimental crafting recipes stay hidden.
- Set progress is shown per set under the worn slots.

### Decisions on open questions (Nov 9, 2026)

- The Workshop stays usable at any location without combat.
- The enhancement animation can be skipped with a press. The chance, result and confirm stay.
- There is no "enhance until" repeat: each attempt is a deliberate press.
- The bag has no weight or carry limit.

## 5. Skills and fusion (Claude's design)

Two windows: Skills (the full list, the 6 pinned slots and weapon proficiency) and Fusion.

### Skills window

```
┌──────────────────────────────────────────────────────────────┐
│ Skills                                              [Close]   │
│ [All] [Attack] [Defense] [Recovery] [Status] [Tagged]  Search  │
├──────────────────────────────────────┬───────────────────────┤
│ Skill list                           │ Selected skill         │
│ Brace        Novice Lv 4   Stance    │ Description            │
│ Lunge        Novice Lv 6            │ Stage, level, XP bar   │
│ Mend         dimmed: other class     │ Tag, needs, class lock │
│ Sword Prof.  Novice Lv 8   weapon    │ Counts toward Hero: yes│
│ ...                                  │ [Pin] [Stage-up info]  │
├──────────────────────────────────────┴───────────────────────┤
│ Pinned: [1] [2] [3] [4] [5] [6]        Active: Stance/Aura    │
└──────────────────────────────────────────────────────────────┘
```

| Part | Design |
| --- | --- |
| List and filters | All skills with stage and level, filtered by type (attack, defense, recovery, status, tagged), searchable, and sorted by last used by default. Class-locked skills of other classes are shown dimmed with "other class" so the player can still use them as fusion ingredients |
| Selected skill | Description, stage and level with a proficiency bar, tag, needs (for example a shield), whether it is class-locked, and whether it counts toward the Hero power score (marked when it is among the strongest skills that count) |
| Pinned slots | The 6 pinned slots from the fight screen are edited here by pressing Pin on a skill. They do not count in the Hero power score |
| Active tags | A line showing the active Stance and Aura (chosen free before a fight) and the other tag slots, matching the fight screen |
| Stage-up | When a skill reaches Lv 10, it shows "Ready to advance" and what it needs: a master's trial (weapon and class skills), with the master's name and floor, or a stage catalyst item (all other skills) with the count held |
| Weapon proficiency | A separate section at the top of the list with one row per weapon type, its stage and level, and the weapon grades it allows |

### Fusion window

```
┌──────────────────────────────────────────────────────────────┐
│ Fusion                                              [Close]   │
│  [Ingredient 1]  +  [Ingredient 2]  +  [Ingredient 3 optional]│
│  Catalyst: [optional item]                                    │
│                                                              │
│  Result: known recipe -> shows the result and its stage       │
│          unknown      -> "Unknown combination. Random result"  │
│                                                              │
│  The ingredients are always used up.            [Fuse]        │
└──────────────────────────────────────────────────────────────┘
```

| Part | Design |
| --- | --- |
| Slots | Two ingredient slots, an optional third, and an optional catalyst slot. Skills are picked from the Skills list, including other-class skills from books |
| Known recipe | If the combination is in the Journal, the result skill and its stage are shown before fusing, since a discovered recipe always works |
| Unknown combination | Shows only "Unknown combination, the result is random". The hidden traits and the odds are not shown, because they would reveal the traits |
| Warning | A line always says the ingredients are used up. A confirm appears before fusing |
| Safe-experiment hint | A skill taught by a master shows a small "can be learned again from the master" mark, so the player knows that experimenting with it costs nothing lasting |
| Result | Shown as a new skill card with its stage and level, with a short animation. A scrap result is shown as a scrap skill. The recipe, if new, is recorded in the Journal |

### Layout (mobile)

The Skills list is a single column with the selected skill's details opening as a sheet. The Fusion window stacks the slots vertically, and the Fuse button is fixed at the bottom.

### Decisions (Claude's choices)

- The full skills window has filters by type, search, and defaults to last used, with the 6 pinned slots edited from it. This answers the open question from screen 2.
- Weapon proficiency is a section of the Skills window, not on the status screen. This answers the open question from screen 3.
- Fusion never previews an unknown combination, and never shows hidden traits or odds.
- A skill that counts toward the Hero power score is marked in the list.

### Decisions on open questions (Nov 9, 2026)

- After an unknown fusion, one neutral line tells the player whether the ingredients resonated weakly (0 to 1 shared traits) or strongly (2 to 3). It never names a trait.
- The player cannot write notes on a skill's traits.

## 6. Quests and Journal (Claude's design)

Two windows. Quests is the list of what the climber is doing. Journal is what the climber has learned.

### Quests window

| Part | Design |
| --- | --- |
| Tabs | Main, Side, Class master, Found secrets, Done |
| Quest row | Title, giver and location, a one-line objective, and the recommended level. A track toggle puts it in the small tracker on the main screen (the main quest is always tracked, plus up to 3 more) |
| Quest detail | The story so far in a few lines, the current objective, and rewards when known. No map or marker is shown, because floor 8 has no map and the game prefers directions in words (for example "ask the clockmaker in the tower") |
| Main chain | Shows chapters of the main quest with the current chapter highlighted and finished chapters collapsed. Floor 6's six-chapter questline is shown the same way |
| Class master | The teaching chain, the three stage-up trials and the advancement quest of the climber's own class. Trials unlock when the skill reaches Lv 10 |
| Found secrets | Hidden events the climber has discovered, shown only after discovery as a short line. Undiscovered ones are not shown at all, so the game does not reveal that they exist |
| Done | Finished quests with the ending chosen, so the player can remember how a floor ended |

### Journal window

| Tab | Design |
| --- | --- |
| Recipes | The fusion journal: every discovered fusion recipe with its ingredients and result, and discovered crafting recipes. Entries are added automatically when found |
| Clues | Clues from hidden events, books and NPCs, grouped by floor. This includes Esther's clues, which are kept in a separate section at the top because they form the hidden thread of the story, and signs of the Order of the Descent, collected as small entries |
| Bestiary | Enemies the climber has met, with art, floor, tier and drops seen. Weaknesses are not recorded, except for a Seeker who took the Truthseer branch |
| Floor notes | A short summary of each floor's world, rule and how the climber ended it, for rereading the story later |

### Layout (mobile)

Both windows are full-height sheets with a scrolling tab strip. Quest rows are single lines that expand to show details.

### Decisions (Claude's choices)

- Quests give directions in words, not map markers.
- Undiscovered secrets are never shown, not even as empty rows.
- Esther's clues and the Order's signs get their own place in the Journal, since they are the story's long thread. Her clues are labelled "Notes in one hand" until Arc 5 reveals her name.
- The tracker shows the main quest plus up to 3 more.
- Only Truthseer gets weakness entries in the Bestiary (decided Nov 9, 2026), so that branch's signature stays worth choosing.

### Decisions on open questions (Nov 9, 2026)

- Floor 8's path notebook is a Journal tab that appears only while the climber is on floor 8.
- The Bestiary has descriptions only, no exact numbers.
- Done quests are read-only. Clear grades are raised by replaying the whole floor (see screen 1).

## 7. Dialogue scenes (Claude's design)

The screen used for talking to people, shops, masters, and story scenes. It stays on the main screen's scene and covers the lower part with a text box, so the player keeps the sense of place.

### Layout (desktop)

```
┌──────────────────────────────────────────────────────────────┐
│ (scene background art, with the speaker's portrait on a side) │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ Speaker name         Bond ●●●○○                       [Log]   │
│ Dialogue text, short lines, calm voice                        │
│                                                              │
│ [Choice 1]  [Choice 2]  [Choice 3]  [Choice 4]                │
│ [Give gift]  [Shop]  [Ask about ...]  [Leave]                 │
└──────────────────────────────────────────────────────────────┘
```

| Part | Design |
| --- | --- |
| Text box | Fixed to the bottom, with the speaker's name, the bond level as pips (if the NPC can be bonded), and short lines of text. Pressing advances; a Log button shows earlier lines |
| Portrait | The speaker's portrait on one side of the scene. A scene without art falls back to a name card |
| Choices | Up to 4 choice buttons. The option an NPC likes is never marked, so the player learns from the NPC's reaction. A choice available only to a certain class (for example the Trickster's special options) shows a small class mark |
| NPC actions | A second row of buttons depends on the NPC: Give gift (opens the Items tab of the bag filtered to gifts), Shop, Ask about (rumors and clues unlocked by the bond level), and Leave |
| Bond change | When a bond rises, a small note appears (for example "Friendly reached"), not a pop-up that blocks the text |
| Weighty choices | A choice that decides how a floor ends (for example the three endings of floor 3) is marked and asks for a confirm, because it shapes the clear grade, though the floor can be replayed |
| Order's hint | The Order's white-chair symbol appears as a small glowing mark in the scene corner when an Order hint is present. It is the only place the glowing white color is used in the scene |
| Shops | A shop is a window over the dialogue with a two-column list, the price shown with any bond discount applied, and a short line noting the discount |

### Layout (mobile)

The text box takes the lower third and the choices stack vertically as full-width buttons. The portrait sits above the box.

### Decisions (Claude's choices)

- The text box covers only the lower part of the scene, and choices are limited to 4.
- Liked options and liked gifts are never marked.
- Floor-ending choices need a confirm.
- Bond changes are shown as small notes.
- A speaker without a portrait is shown with a name card (confirmed by Phat, Nov 9, 2026).

### Decisions on open questions (Nov 9, 2026)

- Text speed is a setting (Normal, Fast, Instant). A press finishes the line and the next press advances. Auto-advance is off by default. Skip works only on lines already seen.
- Every scene uses the same text box in Arc 1, with a scene fade at the end of a floor.

### Open questions

- How voice, music and sound are handled; no audio is designed yet.

## 8. Online boards (Claude's design)

Online features follow 05 Online. This section only covers how they appear on screen. Some are objects in the world (so players find them by exploring), and a few are available from the menu so players can check them anywhere.

### Where each feature appears

| Feature | On screen |
| --- | --- |
| Guestbook, notice board | Objects at Rest Town (floor 2) under Go to or Talk to. They can be used only there |
| Echoes | NPC climbers at their locations, shown in the Talk to row with an "Echo" mark. Talking shows the build, with no fight or trade buttons |
| Hall of echoes | A location on floor 9. It lists echoes as display figures, for viewing only |
| Notes at key spots | A faint note or sign in the scene corner. Pressing it opens the text. A "Leave note" button appears only at key spots |
| Wall board and clear grade board | Objects at Rest Town, and also read-only in the Board window (see below) |
| Path statistics | Shown right after clearing a floor, and later in the Board window |

### Board window (menu)

| Tab | Design |
| --- | --- |
| Wall | Where climbers are stuck: counts at each wall floor, first clears and best grades. Read only |

### Layout (mobile)

The Board window is a full-height sheet with a scrolling tab strip. Notes open as a small card over the scene.

### Decisions (Claude's choices)

- Guestbook and notice board are in-world objects at Rest Town only. The wall board and clear grade board are objects there too, with read-only copies in the Board window, so players can check them without a trip to floor 2.
- Echoes are NPCs in the Talk to row with an Echo mark and no fight or trade button.
- The Board window also holds the climber's own notes and the echo on/off switch.
- Shared features never block single-player play.
