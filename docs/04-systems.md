# 04 Systems

Power comes from levels, skills, equipment and combinations of them. Items, skills and materials that are "floor-exclusive" are exclusive only because they exist in that world and nowhere else, not because they are locked away. Fighting monsters for EXP and drops, including farming, is a normal way to play. Nothing is useless: even weak skills and plain materials can matter for fusion and crafting. Numbers are not designed yet, except the draft numbers in Stats, Levels, Defeat, Bonds, Hero power grade, Skills, Skill tags, Weapon mastery, Skill fusion, Equipment, Classes, Masters and Watchers.

## Grade scale

F → E → D → C → B → A → S → SS → SSS, plus Unique/Hidden for one-of-a-kind items. Letter grades are used for equipment, for the Hero power grade of a climber, and for floor clears. Skills and weapon mastery do not use letter grades; they use stages with levels (see Skills). In the story, grades are the Tower's way of saying how heavy a thing is, so a climber with no past is never sent blind into a floor.

## Systems

| System | Design |
| --- | --- |
| Levels and EXP | Levels come from EXP gained by fighting monsters, completing quests, clearing floors and finding hidden events (see Levels below) |
| Defeat | A defeated climber returns to the last safe point and loses a little EXP progress and one bond level; items, skills and progress are kept (see Defeat below) |
| Bonds | A 5-level relationship with named NPCs, raised by talking, helping, gifts and choices. Higher levels unlock scenes, shop discounts, quests, clues and rewards, and some teachers only teach a bonded climber (see Bonds below) |
| Stats | 4 core stats the same for every class, plus 3 secondary ratings derived from them (see Stats below) |
| Hero power grade | A score from stats + skills + gear, where no single part can supply more than half of the score needed for a grade (see Hero power grade below). Gates some floors and quests |
| Classes | 6 starting classes, the hidden class Seeker (a full class chosen by refusing the Tower's gift), and 3 add-on hidden classes found later (see Classes below). Classes differ by stat growth and by class skills |
| Class advancement | 3 tiers (around floors 10, 25, 40) via advancement quests run by class masters. At the first tier every class chooses one of two branches; a branch gives a signature trait and three class-locked skills (see Advancement branches). The first tier opens after clearing floor 10 (the Wall Seal). Classes that start weaker gain more from advancement |
| Masters | Teachers scattered across the Tower: weapon masters, class masters, hidden masters and wandering masters (see Masters below) |
| Free travel | Climbers can move up and down the Tower freely between cleared floors, so they can return to old floors to learn, craft, farm or replay |
| Weapon mastery | A skill for each weapon type (for example Sword Proficiency) with stages and Lv 1–10, like other skills. Any class can learn any weapon type (see Weapon mastery below) |
| Skills | Every skill has a stage (Novice, Intermediate, Advanced, Master, Grandmaster) and Lv 1–10. Level rises with use in fights, more from tougher enemies; at Lv 10 it can move up a stage (a master's trial for weapon and class skills, a catalyst item for the rest). There is no limit on how many skills a climber can use; every learned skill that is compatible can be used, some skills are class-locked, and some carry a tag that lets only one skill of that tag be active at a time (see Skill tags). Only the strongest skills count toward the Hero power score. A large pool of skills, many of them weak "scrap skills" (see Skills below). Class skill books let a climber own the first skills of other classes as fusion ingredients (see Class skill books) |
| Skill fusion | Combine 2 or 3 skills into a new one by experimenting; recipes are hidden and discovered by trying, and the odds of an unknown combination depend on the hidden traits the ingredients share (see Skill fusion below) |
| Secret fusion recipes | Not shown in game; clues from hidden events, books, NPCs or experimenting; some need skills from 3 floors and yield the strongest skills |
| Titles | Passive. Equip 1 for its full bonus; every collected title gives a small permanent bonus |
| Equipment | 6 slots, grades, enhancement whose cap rises by arc (Arc 1 up to +6, up to +10 only in Arc 5) with stones crafted from materials of several floors and protection charms from three sources, and set bonuses at 2, 4 and 6 pieces. Each world has its own set, but gear from anywhere can be as good (see Equipment below) |
| Monster drops and crafting | Each world's monsters drop materials native to that world. All drops can be farmed. Recipes are found by trying; plain materials can matter (see Crafting below). Materials from early floors gain value when combined with later-floor items, giving reasons to revisit old floors |
| Shops | Stock themed to each floor's story |
| Watchers | One shared Attention gauge that pays Watcher coins when play is exciting, plus a slower Favor with each Watcher that unlocks blessings and sudden quests. They first appear on floor 9 (see Watchers below). The roster and what each tips for are in 01 Lore |

## Levels

All numbers are drafts.

| Part | Design |
| --- | --- |
| Level range | 1 to 100, in four bands set by advancement: Lv 1–20 before the first advancement (floor 10), 21–45 before the second (around floor 25), 46–70 before the third (around floor 40), then 71–100 |
| Level cap | The cap rises only by doing the class master's advancement quest. This is a quest gate, not a grind gate. EXP earned at the cap is banked, up to one level's worth (at Lv 20 that is 2,000), and applies when the cap rises; anything beyond that is lost |
| EXP to level up | The EXP needed to go from level L to L+1 is 100 × L (draft; level 1 to 2 needs 100, level 10 to 11 needs 1,000). The total needed to reach Lv 20 is 19,000. The formula for later bands is not designed yet |
| EXP sources | Fighting monsters (a steady source, respawning in field areas, with a bonus for elites, mini-bosses and floor masters), quests (main, side and class master), clearing floors (more for a better clear grade), masters, and hidden events (one-time) |
| Where the EXP comes from | To reach a floor's recommended level (see the table below), the main path (main quests and the fights on the way) supplies about 70% of the EXP, side quests and masters about 20%, and optional fights and farming about 10% (draft) |
| Farming | A valid way to play. Monsters respawn in field areas and their drops can be farmed. Farming makes up for skipped side content and also feeds crafting |
| Diminishing returns | When the climber is far above a floor's recommended level (draft: more than 10 levels), that floor's monsters give almost no EXP, but their drops stay the same. To keep leveling, the climber moves to higher floors, and crafting materials from old floors stay worth farming |
| Recommended level | Each floor shows a recommended level (alongside the recommended Hero grade). Difficulty is fixed per floor and does not scale to the climber |

## Defeat

A defeated climber loses a little, not everything. In the story the Tower takes the memories and bonds the climber made inside it, and they become fuel for the worlds (see 01 Lore); in the game this is a small, rebuildable loss that never destroys items or progress. All numbers are drafts.

| Part | Design |
| --- | --- |
| Where the climber returns | The last safe point: the floor's entrance, or a resting place such as an inn or camp that the floor defines. See Safe points in Arc 1 below |
| What is lost | 10% of the EXP progress toward the next level (the level itself never drops), and 1 bond level with the NPC whose bond was raised most recently (never below Stranger, see Bonds). Bonds can be rebuilt by talking, helping and gifts |
| What is kept | Items, equipment, skills, recipes, the fusion journal, coins, clear grades, quest progress and hidden event discoveries. A defeat never makes the climber redo story steps |
| Falling below a bond level | One-time rewards and skills already taught are kept. Shop discounts follow the current level. Rewards not yet claimed need the level again |
| Memories lost counter | The game counts how many times the climber has been defeated. It has no effect on stats. The story uses it, for example the Innkeeper on floor 2 greets a defeated climber with a detail they no longer remember, the Order's recruiters speak to climbers with many defeats, and Arc 3 reveals where the memories go |
| Floor rules | A floor's own defeat condition applies on that floor (for example, on floor 6 reputation at zero is a fall from grace, and on floor 9 a lost round returns the climber to the barracks and the round can be retried). The loss above applies in every case |
| Online | The counter is not shown to other players |

## Bonds

Bonds are the relationship between the climber and named NPCs (floor masters, townsfolk, teachers). They give the Content factor of clear grades something to count, give defeat something small to take, and gate some teachers. All numbers are drafts.

| Part | Design |
| --- | --- |
| Levels | 5 levels: 1 Stranger, 2 Acquaintance, 3 Friendly, 4 Trusted, 5 Close. Points needed to reach each (draft): 0, 10, 30, 60, 100. Points never decay |
| Raising | A first conversation (+10, reaching Acquaintance), finishing a quest for them (+10 to +20), giving gifts (+5, or +10 for a liked gift, limited per visit), and choosing the option they like in a scene (+5) |
| What each level unlocks | Acquaintance: rumors and basic information. Friendly: a special scene, and a 5% shop discount if they run a shop. ## Hero power grade

The Hero power grade (F to SSS) shows how strong a climber is overall. Each floor shows a recommended grade, and some floors and quests require one. All numbers are drafts.

Power score = stat score + skill score + gear score.

| Part | How it is counted |
| --- | --- |
| Stat score | The sum of the four core stats |
| Skill score | Only the climber's strongest skills count (draft: 12 skills before the first advancement, then 16, 20 and 24 after each advancement tier). Each counts points by its stage (Novice 2, Intermediate 5, Advanced 8, Master 12, Grandmaster 16), scaled by its level (draft: Lv 1 counts 55% and Lv 10 counts in full, 5% more per level). Skills that are class-locked to another class or need a weapon type or item the climber cannot use do not count, and weapon proficiency skills are not counted (see below). Skills that cannot be active together because of a tag still count, since the climber can use each of them. Skills beyond the limit can still be used in every fight and as fusion ingredients; they just add no points |
| Gear score | Each equipped item counts points by its grade (F 1, E 2, D 3, C 4, B 5, A 6, S 7, SS 8, SSS 9), plus enhancement (draft: 1 point per 2 enhancement levels). Set bonuses do not add points |

Weapon mastery is not counted separately. It limits which weapon grades can be used, so it affects the gear score indirectly.

**Cap rule:** no single part can supply more than half of the score needed for a grade; anything above that does not count. This keeps stats, skills and gear all mattering, rewards crafting and skill fusion, and stops one source (such as farming levels alone) from raising the grade. The limit on how many skills count stops a pile of weak skills from filling the skill part; to raise it, the climber has to make their strongest skills stronger, through leveling, moving up stages and fusion.

## Skills

All numbers are drafts.

| Part | Design |
| --- | --- |
| Stage and level | Every skill has a stage (Novice, Intermediate, Advanced, Master, Grandmaster) and a level from 1 to 10 within the stage, for example "Sword Proficiency, Intermediate, Lv 3". Using the skill raises its level |
| Leveling | A skill gains proficiency in fights. In a fight where the skill was used at least once, it gains points equal to the total value of the enemies in that fight, using the same monster points as EXP (normal 1, tough 2, elite 8, mini-boss 20, floor master 40). Using the skill many times in one fight does not give more. Enemies more than 10 levels below the climber give nothing, the same threshold as EXP. The same rule applies to weapon proficiency using the weapon. A skill with no direct use in a fight counts as used when its effect triggers during or right after the fight (for example Scrounge), and then follows the same rule |
| Cost per level | The proficiency needed to go from level n to n+1 is 10 × n × a stage multiplier (Novice ×1, Intermediate ×2, Advanced ×4, Master ×8, Grandmaster ×16). A full Novice stage (Lv 1 to Lv 10) takes 450 points and a full Intermediate stage takes 900. Arc 1 enemies give about 1,100 points in total up to floor 9 |
| Moving up a stage | At Lv 10 the skill can move up to the next stage and start again at Lv 1. How depends on where the skill comes from. Weapon proficiency skills and class skills need a stage-up trial from the matching master (weapon master or class master). All other skills (drops, fusion results, scrap skills, skills from wandering masters, skills that exist only in one world) need a stage catalyst item, one per stage |
| Stage-up trial | A special fight with a condition tied to that skill (for example, defeat an elite while using Counter Strike at least 3 times). It can be retried without limit, and a failure costs nothing. The content of each skill's trial is TBD. A master can only test up to the stage their floor allows (draft: Arc 1 masters up to Intermediate, Arc 2 up to Advanced, Arcs 3 and 4 up to Master, Arc 5 up to Grandmaster), so the climber returns to higher-floor masters as they climb |
| Stage catalyst | An item that drops from elites and mini-bosses of the current arc and can be farmed. One is used per stage. Draft rates: elite 5%, mini-boss 20%, so about 0.35 per sweep on a floor with 3 elites and 1 mini-boss, or about 3 sweeps per catalyst |
| Cooldowns | Skill use is limited only by cooldowns counted in turns; there is no resource pool. Weapon attacks, Stances and Auras have none. A Charge has none on starting, and its release skill has one. A Form has a 5-turn cooldown from use, so it runs 3 turns on and at best 2 off. Every other skill has its own cooldown of 1 to 5 turns. At Mind 30 or higher every cooldown except a Form's is 1 turn shorter, down to a minimum of 1 |
| Using skills | There is no slot limit. The climber can use every skill they have learned, as long as it is compatible. A skill is compatible when it is not class-locked to another class, the climber has equipped the weapon type or item it needs, and no other active skill carries the same tag (see Skill tags) |
| Weapon and item needs | Weapon proficiency skills and the weapon skills they teach need a weapon of that type equipped. Class skills need no particular weapon type unless stated (for example Shield Bash needs a shield). No other skills need a weapon or item in Arc 1 |
| Class lock | Some skills are class-locked: only that class can use them (class skills from class masters are the main case). A skill the climber cannot use is kept in the skill list, does not count toward the skill score, and can still be used as a fusion ingredient. Skills that are not class-locked are open to every class. There is no trading in the game, so a class-locked skill found on a drop is simply kept |
| Skill tags | Some skills carry one of four tags (Stance, Charge, Form, Aura), and only one active skill of each tag can be in effect at a time. Tags are what makes choosing skills matter when there is no slot limit. The full rules, the list of tagged skills and the switching rules are in Skill tags below |
| Skills in the power score | Only the strongest skills add to the Hero power score (see Hero power grade). The rest stay fully usable and can be fusion ingredients |
| Sources | Class masters, weapon masters and wandering masters, quests, bonds, class skill books from drops and the Rest Town market, elites, mini-bosses and floor masters, monster drops, hidden events, rare shop stock, fusion, and skills that exist only in one world |
| Large pool | The game has a large pool of skills, including many weak or odd "scrap skills" (for example a whistle that distracts, a stubborn stance) |
| Scrap skills | Weak on their own, but useful as fusion ingredients. Nothing is useless |

### Class skill books (draft)

A class skill book lets a climber own a first skill of a class that is not their own. The skill is class-locked, so the climber cannot use it and it adds no points, but it is kept and is a normal fusion ingredient. This is what makes recipes with another class's skill possible. All numbers are drafts.

| Part | Design |
| --- | --- |
| What a book is | A one-use item. Reading it adds one Novice, Lv 1 first skill of a class (the 18 first class skills in First class skills below). The Seeker and the add-on skills have no books in Arc 1 |
| Which skill | A book gives a random skill from the 3 first skills of its class that the climber does not own yet, so there are no duplicates. When the climber owns all 3, no more books of that class drop |
| Drops | Elites and mini-bosses on floors 3 to 8 drop a book of that floor's class: floor 3 Mender, floor 4 Duelist, floor 5 Arcanist, floor 6 Trickster, floor 7 Vanguard, floor 8 Ranger. The draft rate is 8% for an elite and 20% for a mini-boss. On the floor of the climber's own class, the book is of the next floor's class instead (Mender on floor 3 finds Duelist books; Ranger on floor 8 finds Mender books), since a climber can relearn their own class's skills from the master free. The Seeker has no own class and finds the floor's class as usual |
| Rest Town market | The merchant sells one class skill book per visit, of a skill the climber does not own, for coins (draft: 400). The stock refills each time the climber returns from another floor |
| Rate in practice | A floor with 3 elites and 1 mini-boss gives about 0.44 books per sweep, so about 2 sweeps per book and about 5 sweeps to hold a specific skill from that class (the order of the three is random) |
| Floor and class | Which floor drops which class's books is left to discovery and is not shown to the player |
| Not tradable | There is no trading, so a book is read or kept by the climber who found it |

### Skill tags (draft)

A tag marks a skill that cannot be in effect together with another skill of the same kind. Most skills have no tag (about one in five carry one), so the climber still uses a wide set of skills; the tags only force a choice among skills that would otherwise stack. All numbers are drafts.

| Tag | Meaning | When it is in effect | Switching |
| --- | --- | --- | --- |
| Stance | A posture held until changed (for example Brace, Iron Wall) | From the moment it is taken until another Stance replaces it or the fight ends | Taking a different Stance costs the turn, so it cannot be switched in the same turn as an attack. The climber picks one Stance for free before the fight starts |
| Charge | A preparation that is released later (for example Flame Lance, Chant, Hold Breath) | The climber holds one stored charge at a time. It is released by the matching skill | Starting a different Charge discards the one being held, so the climber must commit. A Charge held when the fight ends is lost |
| Form | A mode of movement or body that lasts for a few turns (for example Blood-Shadow Step, Smoke Step) | For 3 turns after use, for every Form in Arc 1 (draft) | Using another Form ends the current one at once, with no extra turn cost |
| Aura | A continuing effect that costs something each turn (for example Demon's Mantra, Bark Skin) | While it is switched on. Each Aura costs a percentage of max HP per turn (draft: Bark Skin 1%, Demon's Mantra 4%). If the upkeep would bring the climber to 0 HP, the Aura switches off at the start of the turn instead | Switching on or off costs no turn, but the new Aura starts working at the start of the next turn |

Rules that apply to every tag:

- Different tags stack freely. A climber can have one Stance, one Charge, one Form and one Aura in effect at the same time.
- A skill with no tag has no limit and can be used with anything.
- The active Stance or Aura is chosen before a fight starts for free and shown in the status window.
- Stance, Form and Aura are skills in effect, not statuses, so floor rules that reset statuses (floor 3) do not remove them, but a Charge held at the moment of a reset is kept.
- Fusion: a result carries a tag only if at least two of its ingredients carry the same tag. Otherwise it has no tag.
- Wandering master skills and bond skills can carry tags like any other skill.

## Skill fusion

Fusion needs many skills to experiment with, which is why quests, elites, bosses and teachers give skills freely, including scrap ones. A big pool of skills means many possible combinations, so climbers can build many different sets of skills. All numbers are drafts.

| Part | Design |
| --- | --- |
| Ingredients | 2 or 3 skills, optionally with a catalyst item. The ingredients are always consumed and the result takes their place |
| Hidden traits | Every skill has three hidden traits: element, motion and mind, each with one of six values (see Hidden trait values). The player does not see them directly and learns them by experimenting and from clues. Skills from wandering masters have richer traits (two values in each trait), so they share traits with more skills and open more combinations |
| Sharing a trait | With two ingredients, a trait is shared when they have the same value in it. With three ingredients, a trait is shared when at least two of the three have the same value. A skill with two values in a trait shares it if any of its values matches |
| Known recipes | A recipe the climber has discovered always works and gives the same result. Discovered recipes are recorded in a fusion journal |
| Unknown combinations | The result is random, but the odds depend on how many hidden traits the ingredients share (0 to 3): the more they share, the better the odds. The table below gives the draft odds |
| Result stage | A better result is one stage higher than the ingredients, a standard result is the same stage with a new skill, and a weaker result is one stage lower. All results start at Lv 1 |
| Tags | A result carries a tag only if at least two ingredients carry the same tag (see Skill tags) |
| Class lock of results | A result is class-locked only when every ingredient is locked to the same class. If the ingredients come from different classes, or any ingredient is open to every class, the result is open to every class |
| Failure | There is no penalty beyond the ingredients being used. A scrap result is a scrap skill, which can be an ingredient again |
| Safe experiments | A skill taught by a master can be relearned from that master for free, so experimenting with class skills is safe |
| Scrap skill supply | Arc 1 gives the climber about 40 scrap skills for free from quests, elites, bosses, bonds and ordinary wandering masters (draft), so there is plenty to experiment with |
| Discovery | By experimenting, and by clues from hidden events, books and NPCs |
| Secret recipes | Some need skills from three floors and yield the strongest skills. Arc 1 has 3 (draft), each with three ingredients from three different floors |

### Enhancement stones (draft)

An enhancement stone is a single item crafted from a bundle of materials gathered in several places, so enhancing means a lot of farming across the Tower. All numbers are drafts.

| Part | Design |
| --- | --- |
| Floor material | Every floor has one plain enhancement material, dropped by its monsters and found in its quests and chests (names and drops in Floor materials and drops below). Drops stay the same when the climber is far above the floor, so old floors remain worth farming |
| Stone grades | One grade per target level. Arc 1 has six grades, +1 to +6, because its cap is +6. An attempt for +n uses one stone of grade n |
| Main floor of each grade | Each grade has a main floor whose material it needs, spaced up the arc: +1 floor 1, +2 floor 3, +3 floor 5, +4 floor 7, +5 floor 9, +6 floor 10 |
| Recipe | A stone of grade n is crafted from three floors' materials: 9n of the material of its main floor, 6n of the floor below it and 3n of the floor two below it (floors below 1 count as floor 1). A grade 6 stone is 54 of floor 10, 36 of floor 9 and 18 of floor 8 |
| Rare parts | Grades +5 and +6 also need rare parts dropped by the elites and mini-bosses of their main floor: 2 and 4 parts. The number of those drops per floor is small, so they limit the top levels |
| Gating | A stone needs the material of its main floor, so a climber cannot craft grade n before reaching that floor. At floor 7 the highest possible level is +4, at floor 9 it is +5, and +6 needs the First Wall |
| Arcs | Gear is enhanced with the stones of its own arc: Arc 1 gear uses the materials of floors 1–10, Arc 2 gear uses floors 11–20 with the same pattern, and so on. Materials of other arcs do not work. Later arcs raise the cap by one level each, so their recipes get new grades (+7 and up); those are not designed yet |

## Watchers

The Watchers first appear on floor 9. The roster, their styles and their endings are in 01 Lore. The system has two layers: one shared Attention gauge that is easy to read, and a slower Favor with each Watcher for deeper play. No class is favored: every class can earn Attention and Favor the same way. All numbers are drafts.

### Attention (shared gauge)

| Part | Design |
| --- | --- |
| Gauge | One gauge from 0 to 100 for "how exciting the climber's play is" |
| What raises it | Exciting play, for example: taking a handicap on floor 9 (+3 per risk point), winning below 10% HP (+10), winning a hard fight such as an elite (+10), finding a secret (+5), a first clear of a floor (+15), a bold story choice (+5) |
| What lowers it | Playing safe: it drains slowly (draft: 2 points per fight with no risk, never below 0, so safe farming earns no tips) |
| Tip | When the gauge reaches 100, the Watchers tip 10 Watcher coins (draft) and the gauge falls back to 30 |
| Who gets the share | All the coins go to the climber. Each tip also gives 10 Favor, split among the Watchers by which kind of play caused the Attention, for example a comeback goes to Brio, sparing an opponent to Nalin, a fast win to Voss, a found secret to the Mirror, a broken rule to Varek |

## Stats

Every class uses the same stats. Classes differ by how their stats grow and by their class skills, not by having different stat sets.

### Core stats (4)

| Stat | What it does |
| --- | --- |
| Vitality | HP and the base of Guard |
| Power | Strength of every attack, physical or magical. The damage type comes from the skill and weapon, not from the stat |
| Agility | Speed (turn order), crit chance, and the base of Evasion |
| Mind | Resistance to statuses, cooldowns (see Skills), and the base of Ward |

### Secondary ratings (3)

| Rating | What it does | Base from |
| --- | --- | --- |
| Evasion | Chance to dodge an attack | Agility |
| Guard | Reduces physical damage | Vitality |
| Ward | Reduces magical and special damage | Mind |

The ratings rise from skills, class and advancement branches (for example Bulwark raises Guard, Shadow raises Evasion), equipment, and items that exist only in one world (for example a talisman that resists spirits). They are not trained by repeated exposure, which would reward standing still and taking hits.

Floor rules tie to the stats: status resets use Mind, crit damage ×2 uses Agility, and no healing makes Vitality matter more.

## Classes

The game is solo, so every class must be able to clear floors alone. Classes differ by playstyle, not by party role. The starting class comes from the Tower's gift on floor 1.

**Balance principle:** no floor favors any class. Floor rules apply to every class equally, and class skills do not override them (for example, a class heal does not work on a floor that forbids healing). Balance comes from the growth curve instead: a class that is weaker at the start becomes stronger through class advancement, as the reward for playing it through.

## Masters

Teachers are scattered across the Tower. To learn from one, the climber takes the master's quest, proves themselves in a trial, and delivers what is asked; then the master teaches. Climbers can travel freely, so they can return to a master at any time, and higher floors have better masters who teach more advanced things. A master also runs stage-up trials for the skills they teach, up to the stage their floor allows (see Skills), except that wandering masters' skills use catalyst items (see below).

| Type | Teaches | Who can learn |
| --- | --- | --- |
| Weapon master | Weapon mastery for one weapon type, and its stage-up trials | Every class |
| Class master | Skills of one class, their stage-up trials, that class's advancement quests and the skills of the branch chosen | Only that class |
| Hidden master | An add-on hidden class and its skills, and their stage-up trials | Climbers who find the hidden event |
| Wandering master | Unique skills that belong to no class and no weapon | Every class, once the climber has the bond level and finishes the quest the master asks |

**Fairness rule:** each class master's quest chain, including stage-up trials and the branch quest, has the same length and difficulty, so no class gets an easier path. Wandering masters are optional extras for any class, so this rule does not apply to them.

### Wandering masters (draft)

They appear only on some floors and can be found only by climbers who look for them. Their skills are open to every class and can carry tags. Skills from wandering masters count toward the power score under the usual rule (only the strongest skills count), can be fusion ingredients, and move up stages with catalyst items. - Watchers: Favor unlocks after Arc 1, the stall's rare items, and how hostility and Arc 4 opposition work.
