# Tower RPG — Project Context

Nov 3, 2026 · @Phat

## Overview

A Korean-manhwa-style tower-climbing RPG for the web: turn-based, single-player, with real players competing asynchronously. 50 floors; each floor is its own world with story, rules, quests and secrets. Status: concept design, no code yet. First goal: Arc 1 (floors 1–10) with every system in place.

This tab is the source of truth. If another tab conflicts with it, this tab wins.

**Inspiration:** SSS-Class Revival Hunter, I'm the Max-Level Newbie, Tower of God, Omniscient Reader's Viewpoint, Second Life Ranker. An old single-file HTML prototype was discarded; don't reference it.

### Decided

- Web-based.
- Tech stack (decided Nov 2, 2026; no code until Phat asks): Vite + TypeScript + Svelte for the front end, Supabase for the backend, hosted on GitHub Pages (static site), with all game data (skills, floors, items, recipes) in JSON files separate from the code, so balance numbers can change without touching code and the data is not tied to the framework. Svelte was chosen for the most readable code while learning (Phat has no backend experience); Vue or React with Vite would also work if Svelte proves awkward.
- Backend gets priority: everything other players see (boards, echoes, notes, stats) depends on the server, and numbers sent from a player's machine can always be faked. Start with Supabase alone (database, login, access rules, and server-side functions for validation). If the checks later become too complex (for example replaying fights on the server to verify top clears), add a separate server such as Elysia in front of Supabase without rebuilding the rest. Not needed now.
- Visuals: the game stays turn-based but should have images (floor backgrounds, characters and monsters, item and skill icons) and small animations (damage numbers floating, hit shake, smooth HP bars, scene fades, flashes on criticals and floor clears). These work in the chosen stack without a game engine; heavier frame animation can be added later with a small library.
- Visual direction (decided Nov 2, 2026): dark manhwa with gold, but restrained, "not over the top". Principle: plain, still, with room to breathe. Colors (no more than three main colors): near-black and deep navy backgrounds, matte (not glossy) gold as the accent, and glowing white used only for the Order's white empty chair symbol so it stands out as the one thing that catches the eye. Fonts (two): a plain serif for headings with an old-book feel, and a plain sans-serif for body text that reads well on small screens; no decorative fonts. Frames and effects: thin window borders, no ornate swirls, no sparkle on every button, effects saved for moments that matter (criticals, floor clears). In-game system text is short and neutral, with no overblown wording, because the story's sadness works best in a calm voice. Kept in one shared theme used by every screen.
- UI plan: 1) visual direction, done (see above); 2) sketch the main screens on paper, done on Nov 3, 2026: all eight screens are designed in docs/06-ui.md (main explore screen, combat, character status, bag and equipment, skills and fusion, quests and journal, dialogue scenes, online boards); 3) build a shared set of components once (buttons, window frames, HP bars, item slots, icons); 4) add small animations only at moments that feel rewarding; 5) add art, starting with floor 1 only; 6) design for both desktop and mobile from the start and test with real people. Steps 3 to 6 wait until Phat asks to start building.
- Main screen (decided with Phat, Nov 3, 2026, details in docs/06-ui.md): the explore screen has a top bar (floor and world, recommended level and grade, Tithes, and the Attention gauge from floor 9) with a small always-visible chip for the floor's rule, one background image of the current location in the center, a small character panel (level, EXP, HP) and tracked quests on the right, button lists for where to go and whom to talk to (not pressing on the image, which can be added later), and a seven-button menu (Status, Bag, Skills, Fusion, Quests, Journal, Board) whose windows open over the scene. On mobile the image is on top and the menu is a bottom tab bar.
- Combat screen (decided with Phat, Nov 3, 2026): enemies in a row with a gold frame for elites, mini-bosses and floor masters; a turn order strip; the player's status with four always-visible tag slots (Stance, Charge, Form, Aura); a short combat log; four main buttons (Weapon attack, Skills, Items, Switch Stance/Aura); and 6 pinned skill slots for fast use, while the full list stays behind the Skills button. Skills that cannot be used are dimmed with a reason, not hidden. Pinned slots do not count in the Hero power score.
- Character status (decided with Phat, Nov 3, 2026): a four-tab window (Overview, Titles, Bonds, Floor clears). The Hero power grade is shown as three bars (stats, skills, gear), each with a mark at half of the score needed for the grade, so the cap rule is visible. At the level cap the EXP bar shows the banked EXP.
- Screens 4 to 8 (designed by Claude on Phat's instruction on Nov 3, 2026, "whatever is left before Arc 2, use your judgement"; reviewed and accepted by Phat on Nov 9, 2026, full text in docs/06-ui.md; the Floor clears tab shows only a score for Secrets, and only Truthseer gets weakness entries in the Bestiary): the bag has four tabs (Equipment, Items, Materials, Workshop), and enhancement and crafting happen in the Workshop tab at any location without combat, with the chance of success and the failure result always shown and confirmed before an enhancement; stone recipes are shown plainly while experimental crafting recipes stay hidden. The Skills window has filters by type, search and last-used sorting, edits the pinned slots, marks skills that count toward the Hero score, shows weapon proficiency, and shows when a skill is ready to advance. The Fusion window never previews an unknown combination and never shows hidden traits or odds. Quests give directions in words, not map markers; undiscovered secrets are never shown; the Journal holds recipes, clues (with Esther's clues and the Order's signs kept in their own place), a bestiary and floor notes. Dialogue uses a text box over the lower part of the scene with up to 4 choices, never marks the options or gifts an NPC likes, and asks for a confirm on choices that decide how a floor ends. The guestbook and notice board are objects at Rest Town only, the wall board and clear grade board are read-only in the Board window as well, echoes are NPCs with an Echo mark and no fight or trade buttons, and shared features never block single-player play.
- UI open questions (decided with Phat, Nov 9, 2026; details in docs/06-ui.md): field fights can be fled at a chance based on Agility; resting places use the main screen with a Rest button; floor travel is a list of cleared floors, which is also where a floor is replayed; special-rule floors only add to existing screens; the Workshop works anywhere out of combat; an unknown fusion gives a weak or strong resonance line; floor 8's notebook is a temporary Journal tab; pinned skills have one row with no sets; memories lost is never a number on screen; skip works only on seen lines.
- Turn-based combat, solo play, no party.
- Fixed difficulty per floor (does not scale to player level); each floor shows a recommended Hero grade and a recommended level.
- Real players via "Option B": asynchronous, no simultaneous online play (needs a small backend, now decided as Supabase).
- Online features (Option B scope): guestbook, notice board and wall board on floor 2, echoes (recorded snapshots of other players' climbers shown as NPC climbers, viewable but not fightable), a hall of echoes on floor 9, short notes and preset signs at key spots, path statistics after a clear, and a clear grade board. No real-time PvP and no direct rank fights. The server checks only what is shared; single-player progress stays with the player. Anti-cheat starts with plausibility checks, rate limits and reports (details in 05 Online, which sits in the claude/ folder of the project).
- Online details (draft, decided with Phat, Nov 9, 2026; details in 05 Online): single-player needs no account, and magic-link sign-in is needed only to post or appear to others; signing the guestbook always opens the gate; up to 3 echoes per location; six note presets; word filter plus auto-hide at 3 reports; boards and echoes on by default; recorded runs off at launch.
- Main quests are linear and must be completed to unlock the next floor. Climbers can travel freely up and down between cleared floors.
- 50 floors split into 5 arcs of 10. Build Arc 1 fully first.
- Lore direction: the Tower is a lifeboat that keeps dying worlds as floors; each floor is a different universe (details in 01 Lore).
- Protagonist: a player-created climber who wakes inside the Tower with no past, with one shared motive, to learn the truth of the Tower. No outside world or Earth in the story (details in 01 Lore).
- Creator is dead. Floor 50 is the Tower Master, a devoted servant who keeps the Throne empty and secretly tampers with floors to revive the creator. Watchers are lesser gods and beings sealed on floors 47–49 (details in 01 Lore).
- Revival is possible but false: the memories climbers lose on defeat are collected to assemble a new creator. This fixes the defeat cost and where climbers come from, and adds a fourth ending (details in 01 Lore).
- Five Watchers (two on floor 47, two on 48, one on 49), each leaning toward one ending, plus the Tower Master's history and manner (details in 01 Lore).
- The creator chose to die after seeing the Tower would have to consume others, left the Throne empty on purpose, and left a will and clues across the floors as secrets (details in 01 Lore).
- Names: the creator is Esther (true name, revealed in Arc 5); the Tower Master is Ezra; Watchers are Brio, Nalin, Voss, Nameless (The Mirror) and Varek (details in 01 Lore).
- The Order of the Descent is Ezra's cult: polite followers who wait for the god's descent, with a white empty chair as their sign and the phrase "He will come down." Every floor carries a small hint of the Order, escalating across arcs; the link to Ezra is revealed in Arc 4. The floor template has a Cult hint part (details in 01 Lore, 02 Floor Design and 03 Arc 1).
- Order details for Arc 1 (decided with Phat, Nov 9, 2026): the name stays, roles are flat with no ranks, and only the emissaries and Ezra know the cost (details in 01 Lore). The floor 9 blessing is a small buff with a hidden price on the next defeat, and the floor 10 emissary asks for one memory given freely in exchange for a protection charm (draft, details in 03 Arc 1).
- Esther's clues in Arc 1 (draft, decided with Phat, Nov 9, 2026; text in 01 Lore): three unsigned notes on floors 1, 8 and 10 that ask questions and favor no ending, labelled "Notes in one hand" until Arc 5, plus the Seeker's separate letter.
- Floor 1 is the first world the Tower kept (Esther's home, and Ezra's, the first person she saved from it), a quiet abandoned village with a gentle caretaker as floor master. The starting gift is a starting class; refusing it leads to a hidden class and the first clue from Esther (details in 03 Arc 1).
- Defeat (draft): a defeated climber returns to the last safe point (the floor's entrance or a resting place the floor defines), loses 10% of the EXP progress toward the next level (the level never drops) and 1 bond level with the NPC whose bond was raised most recently (never below Stranger, rebuildable). Items, equipment, skills, recipes, coins, clear grades, quest progress and hidden discoveries are kept, and a defeat never makes the climber redo story steps. The game counts defeats in a "memories lost" counter that has no effect on stats but feeds the story (the Innkeeper's greeting on floor 2, the Order's recruiters, the Arc 3 reveal). A floor's own defeat condition still applies on that floor, and the counter is not shown to other players (details in 04 Systems).
- Defeat and bond values (draft, decided with Phat, Nov 9, 2026; details in 04 Systems): each floor has its entrance and one resting place as safe points; the cost stays 10% EXP progress and one bond level; losing a level keeps one-time rewards and taught skills; bond skills are capped small; any rare bond item fills the charm recipe.
- Bonds (draft): a 5-level relationship with named NPCs (1 Stranger, 2 Acquaintance, 3 Friendly, 4 Trusted, 5 Close; 0, 10, 30, 60, 100 points). Points come from a first conversation (+10), finishing a quest for them (+10 to +20), gifts (+5, or +10 for a liked gift, limited per visit) and choosing the option they like in a scene (+5), and never decay. Levels unlock rumors (2), a special scene and a 5% shop discount (3), their own quest, a 10% discount, a secret clue and one rare crafting item (4), and a closing scene with a choice of a small unique skill or another rare crafting item (5). Rewards are items, materials and small skills, never permanent stat bonuses, and are the same for every class. No floor requires a bond, and the Content factor of clear grades counts bond levels reached. Some teachers (wandering masters) need a bond level (details in 04 Systems).
- Bondable NPCs in Arc 1 (draft): 31 named NPCs, one to four per floor (floor 1 has only the Keeper; floors 4, 6 and 7 have four each). Each likes two kinds of gift and nobody dislikes anything. Each has a Trusted quest with a clue and a rare crafting item, and a Close choice between a small unique skill (scrap level, Novice, open to every class, no tag) and another rare crafting item. The Watchers, the Order's members, hidden masters and enemies cannot be bonded. Wandering masters can, and their bond level is also the gate to their teaching. The full table is in 03 Arc 1.
- Levels and EXP: EXP comes from fighting monsters, quests, clearing floors, masters and hidden events. Farming is a normal way to play. Floor-exclusive means the item, skill or material exists only in that world, not that it is locked away. Monsters drop materials that feed crafting. EXP from far-below floors fades (monsters far below the climber give almost none) but their drops stay the same. The level cap (draft 20, 45, 70, 100) rises only by doing the class master's advancement quest. EXP earned at the cap is banked, up to one level's worth (2,000 at Lv 20), and applies when the cap rises; anything beyond that is lost (details in 04 Systems and 02 Floor Design).
- EXP curve (draft): the EXP to go from level L to L+1 is 100 × L, so reaching Lv 20 takes 19,000 in total. To reach a floor's recommended level, the main path supplies about 70% of the EXP, side quests and masters about 20%, and optional fights and farming about 10%. A climber who plays only the main path trails the recommended level by 1 to 2 levels early and about 4 levels by floor 10, so side content and farming matter. The per-floor budget table is in 04 Systems.
- EXP by source (draft, details and tables in 04 Systems): each floor's EXP is split into fights, quests and floor clear by the floor's combat weight (no combat 0/90/10, light 30/60/10, medium 45/45/10, medium to heavy 50/40/10, heavy 60/30/10). Quests split about 60% main, 30% side and class master, 10% hidden events. Floor clear EXP is a base that grows with the clear grade (×1 to ×3). Monsters are worth relative points by tier (normal 1, tough 2, elite 8, mini-boss 20, floor master 40), which gives per-kill EXP on every Arc 1 floor from floor 1 to floor 10 (for example a normal monster is worth 6 EXP on floors 4 and 10 and 16 on floor 9). Floor 10 is a boss floor at the cap, so it gives exactly one level of EXP, 2,000 (fights 1,200, quests 600, clear 200), banked until the first advancement. Its draft monster counts are 40, 18, 5, 2 and 1.
- Skill leveling (draft): in a fight where a skill was used at least once, it gains proficiency equal to the total monster points of the enemies in that fight (the same points as EXP), counted once per fight, so using it many times in one fight gives no extra. Enemies more than 10 levels below the climber give nothing. The cost from level n to n+1 is 10 × n × a stage multiplier (Novice ×1, Intermediate ×2, Advanced ×4, Master ×8, Grandmaster ×16); a full Novice stage takes 450 points. Weapon proficiency levels the same way. This fits the Arc 1 power calibration (a class skill reaches about Intermediate Lv 4 to 5 by floor 10) (details in 04 Systems). Claude's choice: proficiency comes only from fights that are won, and a Stance held from the start counts as used.
- Moving up a skill stage (draft): at Lv 10, weapon proficiency skills and class skills need a stage-up trial from the matching master (weapon master or class master). A trial is a special fight with a condition tied to that skill, can be retried without limit, and a failure costs nothing. All other skills (drops, fusion results, scrap skills, skills from wandering masters, skills from one world) need one stage catalyst item per stage, which drops from elites and mini-bosses and can be farmed. A master can only test up to the stage their floor allows (draft: Arc 1 up to Intermediate, Arc 2 up to Advanced, Arcs 3 and 4 up to Master, Arc 5 up to Grandmaster), so climbers return to higher-floor masters as they climb. A climber who skips the trials stays at Novice and scores fewer skill points (details in 04 Systems).
- Letter grades (F to SSS) are used for three things only: equipment, a climber's Hero power grade, and floor clears. Skills and weapon mastery use stages instead (see Skills). In the story, grades are the Tower's way of saying how heavy a thing is (details in 04 Systems).
- Floor clear grade: the Tower scores every clear out of 100 points on four factors (Path, Content, Secrets, Style) with weights and conditions set per floor, mapped to F–SSS (F 0–19, E 20–34, D 35–49, C 50–64, B 65–74, A 75–84, S 85–94, SS 95–100, SSS needs SS plus a hidden condition per floor). Rewards scale with grade, and only the best grade is kept, so replaying can raise it. A clear of B or better also gives one guaranteed piece of that world's set. Arc 1's per-floor criteria are in 03 Arc 1 (details in 02 Floor Design).
- Floor 1 stall and starting items (draft; details in 04 Systems): the climber starts with 100 coins (decided with Phat), and as Claude's choices plain pieces are named by slot, and Salves and Draughts also work outside fights.
- Clear-grade rewards and Style (draft, decided with Phat, Nov 9, 2026; details in 02 Floor Design and 03 Arc 1): grades multiply EXP, drops and coins from ×1 to ×3, SSS gives a title, replays pay only the difference, Style has full and half marks per floor with turns counted in the floor master fight, and coins come only from floor clears and quests.
- Hero power grade: a score from stats + skills + gear, where no single part can supply more than half of the score needed for a grade, so farming levels alone cannot raise the grade. Skills count by stage (Novice 2, Intermediate 5, Advanced 8, Master 12, Grandmaster 16), scaled by level from 55% at Lv 1 to full at Lv 10. Only the strongest skills count toward the score (draft: 12 before the first advancement, then 16, 20 and 24), so hoarding weak skills adds nothing; the rest remain fully usable and can be fusion ingredients. Weapon proficiency skills do not count. Gear counts by grade (F 1 to SSS 9) plus 1 point per 2 enhancement levels; set bonuses add no points. Draft thresholds: E 36, D 60, C 90, B 140 (A and above are placeholders). Draft recommended grades for Arc 1: F for floors 1–2, E for 3–4, D for 5–6, C for 7–9, and B for the First Wall, where a typical climber's skill and gear total (about 61) is about 9 short of the 70 needed, so level alone cannot pass it (details in 04 Systems).
- Skills: every skill has a stage (Novice, Intermediate, Advanced, Master, Grandmaster) and Lv 1–10 within the stage, for example "Sword Proficiency, Intermediate, Lv 3". Level rises with use in fights; at Lv 10 the skill can move up a stage. There is no limit on usable skills (details in 04 Systems).
- Skill compatibility (draft): a climber can use every skill they have learned as long as it is compatible. A skill is compatible when it is not class-locked to another class, the climber has equipped the weapon type or item it needs (weapon skills need that weapon type; class skills need none unless stated, for example Shield Bash needs a shield), and no other active skill carries the same tag. A class-locked skill found on a drop is kept, does not count toward the score, and can still be a fusion ingredient. There is no trading. Skills that cannot be active together because of a tag still count toward the power score (details in 04 Systems).
- Class skill books (draft): a book adds one Novice first skill of another class to the climber's skill list (class-locked, so it adds no points and cannot be used, but it is a fusion ingredient). It gives a random skill of that class that the climber does not own, so no duplicates. Elites (draft 8%) and mini-bosses (draft 20%) on floors 3 to 8 drop a book of that floor's class: 3 Mender, 4 Duelist, 5 Arcanist, 6 Trickster, 7 Vanguard, 8 Ranger. On the floor of the climber's own class, the book is of the next floor's class instead (floor 8 wraps to Mender). The Rest Town market sells one book per visit for coins (draft 400), refilling when the climber returns from another floor. A floor gives about 0.44 books per sweep, so a specific skill takes about 5 sweeps. The drops and the market are listed on floors 2 to 8 in 03 Arc 1 (details in 04 Systems).
- Skill tags (draft): four tags, and only one active skill of each tag can be in effect at a time, so the climber can know many but chooses which is active. About one skill in five carries a tag. Different tags stack freely. Stance is a posture held until changed (switching costs the turn; one is picked free before a fight). Charge is a stored preparation (one held at a time; starting another discards the first). Form is a mode lasting 3 turns (a new Form replaces it at once). Aura is a continuing effect with a small upkeep (switching costs no turn but starts next turn). Stances, Forms and Auras are skills in effect, not statuses, so floor 3's status reset does not remove them. A fusion result keeps a tag only if two ingredients share it. The tagged skills known so far are listed in 04 Systems (Skill tags).
- Weapon mastery is a skill for each weapon type using the same stages and Lv 1–10. A weapon master's stage-up trial is needed to move up a stage. Each stage teaches a new weapon skill and allows higher weapon grades (Novice F–E, Intermediate D–B, Advanced A, Master S–SS, Grandmaster SSS). The proficiency skills are not counted in the power score, but the weapon skills they teach are ordinary skills and count if they are among the strongest (details in 04 Systems).
- Skill rules (draft, decided with Phat, Nov 9, 2026; details in 04 Systems): skill use is limited only by cooldowns in turns, with no resource pool, and Mind 30 cuts them by 1 turn. Forms last 3 turns with a 5-turn cooldown. Aura upkeep is a percentage of max HP (Bark Skin 1%, Demon's Mantra 4%) and an Aura switches off rather than kill the climber. Arc 1 counts 12 skills. A skill with no direct use levels when its effect triggers. Weapon stage-up trials follow one template with a condition per weapon. Catalysts drop at 5% from elites and 20% from mini-bosses. Master stage limits stay as drafted, and ratings are not trained by exposure.
- Skill fusion (draft): 2 or 3 skills (plus an optional catalyst) are always consumed. Every skill has three hidden traits, element, motion and mind, each with one of six values (element: Fire, Water, Wind, Earth, Light, Shadow; motion: Thrust, Slash, Strike, Shot, Guard, Flow; mind: Calm, Fury, Cunning, Mercy, Resolve, Whimsy). Skills from wandering masters have two values per trait, so they share traits with more skills. With two ingredients a trait is shared when the values match; with three, when at least two of them match. A discovered recipe always works and is recorded in a fusion journal. An unknown combination is random, but its odds depend on how many hidden traits the ingredients share (0 to 3): with 0 shared it gives a one-stage-higher result 5% of the time, same stage 25%, one stage lower 30% and a scrap skill 40%; with 3 shared it gives 50%, 35%, 10% and 5%. There is no penalty beyond the ingredients being used, and a scrap result is a scrap skill that can be an ingredient again. A result is class-locked only when every ingredient is locked to the same class; otherwise it is open to every class. Skills taught by masters can be relearned free, so experimenting with class skills is safe. Arc 1 gives about 40 scrap skills free so that climbers have plenty to experiment with. The 27 main skills (the 18 first class skills and the 9 wandering master skills) have assigned trait values. Five known recipes exist in Arc 1, with effects and traits drafted: Blazing Lunge (Flame Lance + Lunge, a fiery thrust that burns, open to every class), Cleansing Light (Mend + Cleanse, clears your bad statuses and heals a little for each, Mender), Stoneskin (Brace + Bark Skin, Guard +20% for 3 turns and the first hit weakened, open to every class), Venom Fingers (Poison Dart + Pickpocket, steal and poison, Trickster) and Stumble Feint (Feint + Pratfall, the enemy's next attack misses and it may lose its next move, open to every class) (details in 04 Systems).
- Skill content (draft, decided with Phat, Nov 9, 2026; details in 04 Systems): the five known recipes have numbers and cooldowns, Arc 1 has 3 secret recipes, one odds table covers three-skill fusion and all stages, books keep 8% and 20% with the floor mapping hidden, the fierce master's skills have values, and class masters teach only the first three skills in Arc 1.
- Arc 1 skill list (draft, Claude's choices, accepted by Phat on Nov 9, 2026; full list in 04 Systems): 40 scrap skills with 8 tagged, 18 weapon skills, values and traits for the 31 bond skills, traits for add-on class skills, and 3 secret recipes.
- Crafting: the game has a large pool of materials, including plain ones, given freely by quests, elites and bosses. Recipes are hidden and found by experimenting. Nothing is useless, and failures give scrap results that can be ingredients (details in 04 Systems).
- Equipment: 6 slots (weapon, head, body, gloves, boots, accessory), grades F to SSS, and weapon types open to every class (sword, sword and shield, axe, short sword, staff, tome, bow, mace, cards, plus world-specific weapons). Gear from anywhere can be as good as a set (details in 04 Systems).
- Equipment sets (draft): each world has its own 6-piece set with bonuses at 2, 4 and 6 pieces, strong but never required, and pieces from different sets can be mixed (2 + 2 + 2 gives three 2-piece bonuses). The 2-piece bonus is a small stat bonus every class can use equally, the 4-piece bonus is a rule tied to the world's theme, and the 6-piece bonus is a signature effect. Bonuses are the same for every class, do not depend on the weapon type, and do not count toward the Hero power score. Pieces drop from the world's elites, mini-bosses and floor master or are crafted; the weapon piece can be crafted as any of 3 weapon types; a piece's grade is the recommended Hero grade of its floor. Floor 2's set comes from the market, quests and hidden events. All ten Arc 1 sets are designed as drafts (for example floor 3's Healer's set makes good statuses last 1 turn longer at 4 pieces, and floor 10's Wall Defender's set makes leaked rules affect you 25% less at 6 pieces); the full table is in 04 Systems.
- Enhancement (draft): the cap rises with each arc, so +10 is a late-game goal: Arc 1 up to +6, Arc 2 up to +7, Arc 3 up to +8, Arc 4 up to +9, Arc 5 up to +10. Chance of success by target level: +1 100%, +2 95%, +3 90%, +4 85%, +5 80%, +6 70%, +7 60%, +8 50%, +9 40%, +10 30%. A failure drops the item 2 levels, except attempts for +1 to +3, which never drop; items are never destroyed; a protection charm used on an attempt prevents the drop. Each attempt uses one enhancement stone of the grade that matches the target level. On average +4 takes about 5 attempts, +6 about 10 and +10 about 132 (about 17 with a charm on every attempt) (details in 04 Systems).
- Enhancement stones (draft): a stone is one item crafted from a bundle of materials from three different floors. Every floor has one plain enhancement material that all its monsters drop. Arc 1 has six grades (+1 to +6), each with a main floor spaced up the arc (+1 floor 1, +2 floor 3, +3 floor 5, +4 floor 7, +5 floor 9, +6 floor 10). A grade n stone needs 9n of its main floor's material, 6n of the floor below and 3n of the floor two below, and +5 and +6 also need 2 and 4 rare parts from the elites and mini-bosses of their main floor. A stone needs its own main floor's material, so at floor 7 the most a climber can reach is +4, at floor 9 it is +5, and +6 needs the First Wall. Gear is enhanced with the stones of its own arc. For one piece: +4 takes about 220 materials, and +6 about 640 materials and 9 rare parts (about 470 and 8 with charms). A typical climber's six pieces at +4 by floor 10 take about 1,300 materials. The full recipe table is in 04 Systems.
- Floor materials and drops (draft): Straw Thread (floor 1), Road Ash (2), Hour Shard (3), Inner-Energy Iron (4), Spirit Wax (5), Court Silk (6), Rail Scrap (7), Elder Bark (8), Arena Sand (9), Wall Stone Dust (10). Floor 2 has no combat, so Road Ash comes from quests, chests and the market, which sells up to 30 per visit. Per kill, a normal monster drops 1, a tough one 2, an elite 6 (15% chance of a rare part on floors 5–10), a mini-boss 15 (40% chance of a rare part) and a floor master 30 on the first clear. A sweep (every field monster of a floor once, they respawn on re-entry) gives about 37 to 136 materials depending on the floor, and the main path already gives about 60% of a sweep. One piece to +4 takes about 3 sweeps, six pieces to +4 about 12 extra sweeps, one piece to +6 about 11 sweeps and six pieces to +6 about 65 sweeps, with the rare parts of floors 9 and 10 as the bottleneck (details in 04 Systems).
- Real time of farming (draft, deliberately not eased): a sweep counts only the field monsters, not story, quests or exploration, which are extra. With assumed fight lengths (normal 20 s, tough 40 s, elite 2 min, mini-boss 4 min, plus 30% for walking and resting) a sweep takes about 15 minutes on floor 1, 28 on floor 3, 36 on floors 4 and 5, 43 on floor 6, 47 on floor 7, 41 on floor 8, 53 on floor 9 and 56 on floor 10. One piece to +4 is about 1.4 hours, six pieces to +4 about 6.4 hours of extra farming, one piece to +6 about 8.4 hours and six pieces to +6 about 50 hours (about 33 on floors 9 and 10), roughly twice the length of the Arc 1 story (about 25 hours). Phat chose to keep these numbers and not make the game easier. The times are guesses from the assumed fight lengths and must be checked in real play (details in 04 Systems).
- Item details (draft, decided with Phat, Nov 9, 2026; details in 04 Systems): material names are final, item grade caps enhancement (F–E +4, D–C +5, B and above the arc's cap), success rates do not vary by grade, set pieces are named set plus slot and have about 10% lower base stats than the best crafted piece at the same grade, and each floor's weapon piece offers one melee, one magic and one agile type.
- Protection charms (draft): three ways to get one, none enough alone. Drops: the first clear of each floor master on floors 5–10 gives one, and elites (draft 2%) and mini-bosses (draft 5%) on floors 5–10 drop them rarely. Crafting: 3 rare parts from elites and mini-bosses of floors 5–10 plus 1 rare crafting item from a bond (the Trusted reward, or the Close item). Watcher stall (from floor 9): sold for Tithes, with the price rising 25% per charm bought. A charm only matters for attempts at +4 and above. A piece fully protected from +0 to +6 uses about 4 charms, so Arc 1 supply covers all six pieces; the pressure grows in later arcs (details in 04 Systems).
- Watchers system (from floor 9): one shared Attention gauge (0–100) rises with exciting play (risky choices, near-death wins, hard fights, secrets, first clears) and drains when the climber plays safe; at 100 the Watchers make an offering Tithes and it falls to 30, with the offering split by the style of play that earned it. A slower Favor with each of the five Watchers unlocks their blessings, sudden quests and, in Arc 4, their say in the war and the ending. Tithes stay with the climber; defeat does not take them. No class is favored (details in 04 Systems).
- Watcher numbers for Arc 1 (draft, decided with Phat, Nov 9, 2026; details in 04 Systems): an offering is 10 Tithes, safe farming earns no offerings, each offering splits 10 Favor by style, Favor levels are at 10, 30 and 60, charms start at 30 Tithes, the five blessings cost 10 Tithes for 5 fights, and sudden quests pay 5 Tithes and 5 Favor.
- Floor 1 script (draft by Claude, shipped under Phat's standing approval of Nov 10, 2026; details in 03 Arc 1): every Floor 1 location, Keeper scene, Tower line and quest has text in the data files.
- Dialogue and gifts (draft, Claude's choices; details in 04 Systems Bonds and 06 UI): scenes are data, liked options are unmarked and pay once, and each NPC takes one gift per visit.
- Floor 1 encounters (draft, Claude's choices; details in 03 Arc 1): five encounters from Straw Remnants to the Gate Scarecrow, with move lists in the enemy data. The simulator puts every encounter above its turn target, to be tuned in play.
- Balance simulator (Claude's choice, details in 04 Systems): `npm run sim` runs seeded fights through the real engine and data and compares each tier with its turn target.
- Combat formulas (draft, decided with Phat, Nov 9, 2026; details in 04 Systems): damage uses a ratio against Guard or Ward, attack is Power × 2 plus weapon attack, fight length targets are set per tier, and enemy base values are set per floor. The First Wall master stays near a coin flip without preparation.
- Combat rules and values (draft, Claude's choices, accepted by Phat on Nov 9, 2026; details in 04 Systems): one action per turn, no HP regeneration outside resting, fights of 1 to 3 enemies, hidden enemy intent, one weak Element per enemy, statuses, consumables and prices, 20 crafting recipes, values for class and master skills, and at most 2 healing items per fight. Floor scripts are written as build tickets, starting with floor 1 as a playable slice.
- Balance check fixes (decided with Phat, Nov 9, 2026; research in docs/research/arc1-balance-check.md): skill level and stage now scale effects, armor enhancement adds Guard and Ward, Intermediate proficiency allows grade B weapons so +6 is reachable in Arc 1, enemy Mind, rounding, a damage roll and the cooldown meaning are defined, Arcanist Charges are worth using, and enemy values are retuned.
- Stats: 4 core stats the same for every class (Vitality, Power, Agility, Mind) and 3 secondary ratings (Evasion, Guard, Ward) derived from them. The ratings rise from skills, class and branches, equipment and items from one world (details in 04 Systems).
- Classes differ by stat growth and by class skills. Draft numbers: classes start with 17 to 20 total stat points, gain the same total per level, and the weak-early classes gain much larger advancement bonuses (+27 over three tiers versus +12 for strong-early classes), so they catch up at the first advancement. Each class has three first skills learned from its class master, which are class-locked (details in 04 Systems).
- Six starting classes (Vanguard, Duelist, Arcanist, Ranger, Mender, Trickster) (details in 04 Systems).
- Hidden classes (draft): the Seeker is a full class, chosen by refusing the Tower's gift on floor 1; it starts at 16 stat points (below the weak-early classes' 17) with +30 over three advancement tiers, has no teacher (it learns from Esther's letter and clues), and its signature trait Insight marks hidden things faintly. The other three are add-on classes found during the climb, which sit on top of the climber's own class instead of replacing it: Chronicler (hidden event on floor 3, taught by the old clockmaker), Merit-Walker (floor 5, taught by the last monk, a spirit) and Defier (floor 9, taught by a pit fighter who never took a handicap). An add-on class gives three class-locked skills and one signature trait, while stat growth and advancement stay with the original class, and it has no tiers or branches of its own. Names are working names (details in 04 Systems; the hidden masters' scenes are in 03 Arc 1).
- Advancement branches (draft): at the first advancement (after floor 10) every class chooses one of two branches, 14 in total with the Seeker's two. Besides the stat bonus, a branch gives a signature trait (about 10 to 25%, larger only when conditional) and three class-locked skills taught by the class master, with equal quest effort for every branch. Bulwark, Scavenger, Sword Saint, Reaver, Elementalist, Fusionist, Pathfinder, Sharpshooter, Lifewarden, Apothecary, Silver Tongue and Shadow are the 12 for the six starting classes; the Seeker's are Truthseer (enemy weaknesses stay known) and Lorekeeper (clues and hidden events give 15% more rewards), and it learns its skills from Esther's third clue and the Wall Seal on floor 10. Names, skills and numbers are drafts; the full table is in 04 Systems.
- Class balance: no floor favors any class, and floor rules apply to every class equally. Classes that start weaker get stronger through class advancement as their reward (details in 04 Systems).
- Masters: teachers are scattered across the Tower in four types (weapon masters for every class, class masters for one class, hidden masters for add-on hidden classes, and wandering masters). Learning means taking a quest, passing a trial and delivering something. Higher floors have better masters. A weapon or class master also runs the stage-up trials for the skills they teach, with equal effort per class. In Arc 1, class masters sit on floors 3–8 as side quests (details in 04 Systems and 03 Arc 1).
- Wandering masters (draft): skilled people who belong to no class or weapon and teach unique skills to every class. They appear only on some floors and only to climbers who look for them. Most are ordinary teachers of odd, weak, scrap-level skills (two per teacher; they need bond Friendly and a small errand). A rare few are fierce teachers who teach three strong skills and are not tightly balanced on purpose, because their power is paid for by finding them first, bond Trusted and a long hard quest. Nothing on any floor requires them. Their skills can carry tags, count toward the power score under the usual rule, are fusion ingredients with richer hidden traits, and move up stages with catalyst items. Arc 1 has four: the Retired Heavenly Demon on floor 4 (fierce: Heaven-Splitting Palm, Blood-Shadow Step, Demon's Mantra), the court jester on floor 6 (Pratfall, Mockery), the Station tinkerer on floor 7 (Jury-Rig, Scrounge) and the forest hermit on floor 8 (Quiet Step, Bark Skin) (details in 04 Systems and 03 Arc 1).
- Class master chain (draft, the same for every class; floors 3–8 in 03 Arc 1): 1) the teaching chain written in each floor, ending with the three first skills; 2) three stage-up trials, one per skill, available when that skill reaches Lv 10, each a special fight with a condition tied to the skill, retryable with no penalty; 3) the advancement quest after floor 10, where the climber returns to the master, chooses one of two branches, passes one branch trial and learns the three branch skills (the level cap rises to 45). 03 Arc 1 lists the three trials and two branch trials of each of the six classes.
- Arc 1 content gaps (draft, decided with Phat, Nov 9, 2026; details in 03 Arc 1 and 04 Systems): named NPCs go by title until their true name is revealed at Close or the floor's end; each floor from 3 to 10 has a named exclusive skill; floor 4 has 8 weapon elders as one-time duels; floor 9 teaches Arena Gear.
- Floor 2 is a pilgrims' waystation world with an Innkeeper as floor master, who remembers climbers who forgot her. Quest board, guestbook messages and rankings are its online hooks (details in 03 Arc 1).
- Floor 3 is a village looping the last day of its world because a healer wished her sick daughter's last day would never end. Three ways to end it: cure, release, or leave it. The old clockmaker, the hidden master of the Chronicler, lives in its clock tower (details in 03 Arc 1).
- Floor 4 is a murim world whose sect holds a last tournament to pass its arts to a stranger who can carry them out of the dying world. It introduces weapon mastery. Three ways to end it: accept, decline with honor, or reveal the truth. The Retired Heavenly Demon, a fierce wandering master, hides in the town below the sect (details in 03 Arc 1).
- Floor 5 is the drowned world of the Watcher Nalin: a canal-side house haunted by a family with no one left to make merit for them. Night is when enemies are immortal. Three ways to end it: merit, last wish, or exorcise. The last monk, the hidden master of the Merit-Walker, is a spirit in its half-sunken temple (details in 03 Arc 1).
- Combat: every floor with combat has its own enemies, an elite, a mini-boss and a floor master fight built around the floor rule. Peaceful paths are another hard route, never a skip. Fighting monsters matters for EXP and drops. The floor template has Combat and Floor master fight parts (details in 02 Floor Design and 03 Arc 1).
- Floor 6 is a palace on the eve of a coup, with a long six-chapter questline and heavy combat; a framed villainess is the floor master. Reputation is HP. Witness system: each area is Public, Semi-private or Private and a fight seen there carries a witness penalty (full, half or none), while a few key witnesses (the Empress Regent, the Captain of the Guard, the Duke, the archivist) change standing with their faction; formal duels are lawful; the tools to lower exposure are the same for every class. Three ways to end it: clear her name, side with her, or side with the Crown (details in 03 Arc 1).
- Floor 6 witness values (draft, decided with Phat, Nov 9, 2026; details in 03 Arc 1): the penalty is 10%, 5% or 0 once per fight and can cause a fall from grace; exposure tools have values; the Crown and the Duke's faction have standing from −5 to +5 with missions at +2 and refusal at −3.
- Floor 7 is a subway-station stronghold where a leader decides who gets the city's last healing items. Healing is only from floor-found items, and class heals do not work there. Three ways to end it: evacuate, cooperate, or overthrow (details in 03 Arc 1).
- Floor rule scope (draft, decided with Phat, Nov 9, 2026; details in 03 Arc 1): floor 3's reset clears all statuses on both sides every 10 rounds of a fight, and leaves tag skills and cooldowns alone. Floor 7 allows only healing items found there, remembers the climber's HP across visits, and a defeat returns the climber at 50% HP.
- Floor 8 is a migrating elven forest whose elf Warden is being tampered with by a mark, the same white empty chair seen on earlier floors. Elves teach bow mastery to any class with no class advantage. Three ways to end it: free her, mercy, or seize the seeds. Navigation (no map): natural signs (leaning leaves, the forest's heartbeat, animal tracks, scouts' carved marks) plus the climber's own path notebook of rough sketches that go stale when the forest shifts, a few stable landmarks that never move, scout-made guide items such as a compass that follows the forest's heartbeat, and short notes from other players attached to stable landmarks; the same for every class (details in 03 Arc 1).
- Floor 8 navigation values (draft, decided with Phat, Nov 9, 2026; details in 03 Arc 1): routes shift every 8 moves, sketches fade after one shift and vanish after two, the compass works within 6 moves of the Elder Tree, and scout marks can be wrong after a shift.
- Floor 9 is a colosseum world whose gods watched its Great Games; the Watchers now sit in the empty god seats as projections and officially appear. The undefeated Champion wants to lose. Handicap system: before each bout the climber may take handicaps (self-debuffs) worth 1–3 risk points each, up to a cap per bout (draft: 3 in qualifying bouts, 5 in quarterfinal and semifinal bouts, 7 in the final); risk points raise that bout's rewards and Attention. The list has four groups (Body, Skills, Senses, Resources), is the same for every class, a handicap cannot repeat in the next bout, and taking none is always allowed. "Full cap" means taking the whole cap in a bout. Three ways to end it: Grand Finale (beat the Champion with the final's full cap), Cut the Stream, or Quiet End (no handicaps). The pit fighter, the hidden master of the Defier, lives in the gladiator barracks (details in 03 Arc 1).
- Floor 9 handicap values (draft, decided with Phat, Nov 9, 2026; details in 03 Arc 1): 6 Arena bouts with caps 3, 5 and 7, each risk point adds 15% to bout rewards and 3 Attention, and the handicap list has exact effects.
- Floor 10 (First Wall) is a fortress world held by a wall at the edge of its dissolving; the unraveling leaks two random rules from floors 3–9 in. Counters: each leaked rule has three levels, so no climber is locked out. With no counter the rule runs at full strength, with that floor's item it is weakened by about half, and with that floor's item and skill together it becomes a small advantage. Counters are the same for every class, and level alone cannot pass the Wall. Its Commander wants the defenders witnessed. Three ways to open the gate: Seal the Breach (best), Hold the Line, or Break the Gate. Clearing it opens the first class advancement; the Seeker learns its branch skills here from Esther's third clue (details in 03 Arc 1).
- Floor 10 counter values (draft, decided with Phat, Nov 9, 2026; details in 03 Arc 1): each leaked rule has exact values at full strength, item and item plus skill; items are not used up, and a skill counts at any stage.
