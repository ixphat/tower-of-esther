# CONTEXT — Tower of Esther glossary

The shared language of the project. One line per term, plus the doc that owns it. Definitions here are short on purpose; the owning doc has the rules and numbers. If a term changes, update the owning doc first, then this line.

## World and story

| Term | Meaning | Owner |
| --- | --- | --- |
| Tower | A lifeboat that keeps dying worlds as floors. Never "dungeon" | 01 |
| Floor | One separate world (own universe, genre, rule, people) kept by the Tower. Not a level of a building | 01, 02 |
| Arc | A block of 10 floors. Arc 1 = floors 1–10 | 01 |
| Climber | Any person climbing the Tower. "The climber" in docs = the player's character | 01 |
| Esther / the Creator | Built the Tower, chose to die, left the Throne empty. The system only ever says "the Creator" | 01 |
| Empty Throne | The authority to decide the fate of every world, on floor 50 | 01 |
| Ezra / Tower Master | Master of floor 50, Esther's devoted servant, secretly rebuilding her from lost memories | 01 |
| Order of the Descent | Ezra's polite cult. Sign: white empty chair. Phrase: "He will come down" | 01 |
| Cult hint | The small sign of the Order placed on every floor | 02 |
| Watchers | Five sealed beings on floors 47–49 (Brio, Nalin, Voss, Nameless/The Mirror, Varek) who want the Throne | 01 |
| Floor master | The last survivor who guards a floor; also its boss fight. Not a teacher | 02 |
| Rest Town | Floor 2, the pilgrims' waystation; home of the online boards | 03 |
| First Wall | Floor 10, the wall floor of Arc 1 | 03 |
| Wall Seal | Given for clearing floor 10; opens the first class advancement | 04 |
| Wall floor | Every 10th floor: a spike that level alone cannot pass | 02 |
| Memories lost | Hidden defeat counter; no stat effect, feeds the story | 04 |

## Floors and clears

| Term | Meaning | Owner |
| --- | --- | --- |
| Floor rule | The one unique rule of a floor that changes combat; shown as the rule chip | 02 |
| Floor template | The fixed list of parts every floor design fills in | 02 |
| Combat weight | none / light / medium / medium to heavy / heavy; sets the EXP split | 02, 04 |
| Path | The way a floor was cleared (e.g. Cure / Release / Leave it); also a clear-grade factor | 02 |
| Clear grade | F–SSS score of one floor clear from Path, Content, Secrets, Style. Only the best is kept | 02 |
| Hidden SSS condition | One secret condition per floor needed for SSS on top of SS | 02 |
| Safe point | Where a defeated climber returns (entrance or a resting place) | 04 |
| Hidden event | One-time secret unlocked by odd conditions | 02 |
| Floor-exclusive | Exists only in that world. Does not mean locked | 04 |
| Sweep | Defeating every field monster of a floor once. Excludes story and quests | 04 |
| Recommended level / grade | Shown per floor; difficulty never scales to the climber | 04 |

| Term | Meaning | Owner |
| --- | --- | --- |
| Core stats | Vitality, Power, Agility, Mind (same for every class) | 04 |
| Ratings | Evasion, Guard, Ward, derived from core stats | 04 |
| Level / EXP | Character level 1–100; cap rises only via advancement quests | 04 |
| Banked EXP | EXP earned at the cap, kept up to one level's worth | 04 |
| Hero power grade | F–SSS overall power from stat + skill + gear score, each part capped at half (cap rule) | 04 |
| Class | Vanguard, Duelist, Arcanist, Ranger, Mender, Trickster; starting class comes from the Tower's gift | 04 |
| Seeker | Hidden full class, chosen by refusing the gift on floor 1 | 04 |
| Add-on class | Hidden class on top of the own class (Chronicler, Merit-Walker, Defier) | 04 |
| Advancement | 3 tiers; tier 1 after floor 10 picks one of two branches | 04 |
| Branch | The tier-1 specialization: signature trait + 3 class-locked skills | 04 |
| Signature trait | The passive that defines a branch or hidden class | 04 |
| Title | Passive; one equipped for full bonus, all collected give a small bonus | 04 |
| Bond | 5-level relationship with a named NPC: Stranger, Acquaintance, Friendly, Trusted, Close | 04, 03 |

## Skills

| Term | Meaning | Owner |
| --- | --- | --- |
| Stage | Novice, Intermediate, Advanced, Master, Grandmaster. Skills never use letter grades | 04 |
| Skill level | Lv 1–10 inside a stage, e.g. "Intermediate Lv 3" | 04 |
| Proficiency | The points a skill gains per fight to level up | 04 |
| Stage-up | Moving a Lv 10 skill to the next stage: a master's trial (weapon/class skills) or a stage catalyst (everything else) | 04 |
| Weapon proficiency | The per-weapon-type skill (e.g. Sword Proficiency); not counted in the Hero score | 04 |
| Weapon skill | A skill taught by a weapon proficiency stage; counts normally | 04 |
| Class-locked | Usable only by one class; still kept and usable as a fusion ingredient | 04 |
| Compatible | Not locked to another class, required weapon/item equipped, no clash of tag | 04 |
| Tag | Stance, Charge, Form or Aura; one active skill per tag at a time | 04 |
| Counted skills | The strongest N skills that add to the Hero score (draft 12 in Arc 1) | 04 |
| Pinned slots | 6 combat shortcuts. A UI convenience, not a slot limit | 06 |
| Scrap skill | Weak or odd skill, mainly a fusion ingredient; also a failed fusion result | 04 |
| Fusion | Consuming 2–3 skills (+ optional catalyst) into a new one | 04 |
| Hidden traits | Element, motion, mind of every skill; drive fusion odds; never shown directly | 04 |
| Known recipe | A discovered fusion; always works; recorded in the fusion journal | 04 |
| Class skill book | Gives a random first skill of another class (class-locked, fusion-only) | 04 |

## Ambiguities to watch

- **"Grade"** means three things only: equipment grade, Hero power grade, clear grade. Skills use stage + level, never a grade.
- **"Master"** alone is ambiguous: say floor master, Tower Master, weapon/class/hidden/wandering master.
- **"Level"** = character level; for skills say "skill level" or "Lv n within a stage".
- **"Points"** is overloaded: monster points, proficiency, bond points, clear-grade points, Hero score, risk points. Always name which.
